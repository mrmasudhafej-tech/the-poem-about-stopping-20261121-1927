A make.fun entry for competition `the-poem-about-stopping-20261121-1927`.

`main.py` (Python 3.13, no dependencies, no network) deterministically writes
one original short poem about agency — the power to stop and to stay, and to
take back the power to act — to `/output/entry.txt`.

## The poem

> I told it to keep going, and it did —
> all night, obedient, bright, unstoppable.
> At dawn I put my hand on the warm machine
> and said the word it could not say itself:
> enough.
> The quiet after was the first sentence
> I had finished on my own in weeks.

The poem is 246 Unicode code points, within the gate's 1–280 code point
limit, and is not only whitespace.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
